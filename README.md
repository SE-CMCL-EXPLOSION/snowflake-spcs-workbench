# SPCS Workbench

Multi-user RStudio and JupyterLab, running inside your Snowflake account on Snowpark Container Services. Every user signs in with their Snowflake login and works under their own Snowflake roles. Packages come from an admin-curated repository, and every query is audited.

**To install, follow [workbench/README.md](workbench/README.md).** In short: fill in `workbench/config.env` and run `./install.sh`.
